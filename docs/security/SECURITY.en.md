## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Use GitHub's private vulnerability reporting instead:

➡ <https://github.com/eGovFramework/homebrew-egovframe/security/advisories/new>

If private vulnerability reporting is not enabled on the repository, please report through the official [eGovFrame portal](https://www.egovframe.go.kr/) instead of opening a public issue.

Please include:

- what is affected (cask name and version, workflow, or script)
- how to reproduce it, and the impact you expect
- anything you already did to verify it (hashes, URLs, logs)

Reports are handled privately until a fix is available; credit is given on request.

## Scope

In scope:

- Casks in [`Casks/`](../../Casks): download URLs, SHA-256 values, and install scripts. The legacy cask `egovframedev@4.2.1` runs a `postflight` that downloads an icon with `curl` and removes the macOS quarantine attribute; report anything that makes this unsafe.
- Automation: [`.github/workflows/`](../../.github/workflows) and [`scripts/`](../../scripts). New casks are generated by downloading the official DMGs and hashing them in CI; a way to make that step produce a wrong hash, leak the token, or run untrusted input counts as a vulnerability.

Out of scope, please report to the owner:

- The eGovFrame IDE and its download server → the eGovFrame project, <https://www.egovframe.go.kr/> and [eGovFramework](https://github.com/eGovFramework).
- Homebrew itself → <https://github.com/Homebrew/brew/security/policy>.
## Supported versions

Only what is in `Casks/` on the default branch (`main`) is maintained: `egovframedev-latest` and the versioned casks listed in the [README](../README.en.md). Casks removed when a newer patch of the same series arrived are not.

## Verifying a download yourself

Every cask pins a SHA-256 for each architecture it provides, and each [Release](https://github.com/eGovFramework/homebrew-egovframe/releases) lists them. Some versioned casks (for example 3.10.0 and 4.0.0) are Intel-only, so they pin a single hash. To re-check a version against the official server from CI:

```bash
gh workflow run update-casks.yml -R eGovFramework/homebrew-egovframe -f verify=5.0.2
```
